Git Version Control & SCM Toolchain

Source Code Management (SCM) tracks modifications to source code over time, preserves revision history, enables collaborative branching, and powers continuous integration (CI/CD). This project demonstrates complete professional SCM implementation using Git and includes a standalone Python SCM implementation (mini_scm.py) and Git automation tool (scm_tool.py).

⚖️ SCM Tool Comparison: Why Git?
Feature Git (Chosen SCM) SVN (Subversion) Mercurial (Hg)
Model Distributed (Full local copy) Centralized (Server dependent) Distributed
Branching & Merging Instant, cheap pointers Full directory copy (slow) Named branches (moderate)
Data Integrity Cryptographic SHA-1/SHA-256 Revision numbers only SHA-1 hashing
Offline Operations 100% Full offline commits & logs Requires active network Offline support
Ecosystem & CI/CD Industry Standard (GitHub, GitLab) Legacy, declining Moderate adoption
